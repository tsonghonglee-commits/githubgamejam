# 体素特效、场景奇观与 Boss 环境互动方案

v0.12.8 已回退 v0.12.5 新增的战斗特效，并停用体素特效 Skill。下文的特效提案与当时实现作为历史记录。

这份方案以目前的五系列、第一人称奔跑和真实体素破坏为基础。工业运兵船打开顶棚、运送 Boss、放下后撤离，给出了场景参与出场的参照。后四个系列各做自己的场景机构，让玩家先看到环境预告，再看到 Boss 和实体发生接触，最后从正在变化的场景里继续奔跑。

## 一、补足战斗和演出的体素特效

| 场合 | 要做的效果 | 第一人称验收 |
| --- | --- | --- |
| 普通刀切 | 刃口接触的一拍出短火星或材屑。随着刀移动，切痕和飞出的真实体块沿不同方向展开。金属用跳火与硬片，岩石用成簇粉屑，水墨材质用短促黑红裂迹。 | 同一刀能读出接触位置、切向和体块脱落方向。贴脸碎屑短时退散，方便看第二刀。 |
| 振刀与重型同斩 | 振刀用清楚的金属碰撞、沿来力侧推出的短弧和刃口闪点。重斩根据实际受切面积和断块重量叠加切面、飞块和低频冲击。 | 同一机位能区分轻切、振刀、重斩。四重型同斩单独测长帧和特效并发，保留实材去格与残骸再切。 |
| 入场与死亡 | 工业是火花、铆片和地面尘线，水墨是墨滴与刃尖笔锋，赛博是断续电弧和排焰，海洋是多层贴水白沫，轨道是冷色喷流和热碎片。先做每类一处最需要强化的镜头。 | 效果跟真实刃尖、喷口、脚点或机组故障走。按原速能区分预告、接触和余波。武器或喷口断掉后，相应发射源熄灭。 |

原方案使用现有碎屑、短迹和声音池，并按真实接触规模和世界时间分配近景效果。

## 二、每个场景建立一个可穿过的奇观

每个奇观按「远处辨认、近处掠过、身后退出」设计，路面与近景有明确速度参照，保留玩家跑道和天空道的读图空间。每处先做灰盒，用第一人称原速片段定体量和揭示节奏，再进入材质和细节制作。

| 系列 | 主奇观 | 玩家经过时看见什么 |
| --- | --- | --- |
| 工业 | 吊装穹顶与重型物流线 | 保留现有开顶吊装。扩展远处交错的行车与近处掠过的空吊架，强化建筑尺度和运兵船经过的空间关系。 |
| 水墨 | 峡谷悬寺与层叠石门 | 远处先见跨峡谷的断续山脊与悬寺。通过前景石柱和桥栏时显出垂直落差。内门与纸屏形成分段开合的纵深。 |
| 赛博 | 检修街区上方的分层吊运场 | 在前景街巷上方布置可展开的检修顶和信号梁。地面有装甲坡道，空中有独立吊运净空，层次服务于小队和后续三台载具的入场。 |
| 海洋 | 海锁、外海墙和可见水头差 | 从挡浪墙后突然开到外海，先看见浪墙侧面，再从前景水门间穿过。闸板、引流槽、近浪和远浪使用不同尺度与速度。 |
| 轨道 | 开放式大型坞环与泊舰船腹 | 先从远处读到坞环与泊舰的剪影，再擦过维修桁架进入空旷泊位。引导灯、固定桁架和巨舰之间形成强视差。 |

用 `slay-generation-performance` Skill 把固定奇观与可动机构预建，接入 `series_scenery.gd` 的预热、段落切换和回收。逐场景核对路面连续、真实净空、Boss 实体与机构的位置，以及冷建、首个可见帧和换段的耗时。高重复细节复用网格与材质。独立可动件集中在玩家能辨认的机构上。

## 三、后四系列 Boss 用场景完成出场

| Boss 或编组 | 场景先做什么 | Boss 实际做什么 | 入场后留下什么 |
| --- | --- | --- | --- |
| 水墨宗师 | 悬寺内门的左右石扇与纸屏错拍拉开，露出近景上方的横梁和桥面 | 宗师沿桥外侧越过门梁，近景急坠到桥面。先在接地点压出墨浪，再由存活刃尖切出两道错拍笔锋 | 石门保持打开，纸屑和墨痕有明确退场时间，桥面视线开阔后接战 |
| 赛博四人小队 | 检修顶打开，信号灯沿吊运方向亮起，露出中间净空 | 同一架直升机吊运四人，从真实滑橇处放下四根锁缆，依次解锁。四人各自完成不同落地动作 | 顶棚保持在吊运净空位，空载直升机撤离，场内留下它的声音和飞行方向作为后续线索 |
| 断尾直升机 | 检修顶上方的引导灯反向流动，预告它从离场方向回来 | 刚才投放小队的直升机再次穿过净空，反推回摆进入战位。旋翼下洗推动侧墙灯片和贴地碎屑 | 顶棚逐段停稳，侧墙灯片回弹后保持在开战状态 |
| 裂履主战坦克 | 地面斜坡板落下，门内红灯换成低位路径灯 | 履带沿真实坡面驶入，先前履带落地，再由后履带承重。转车体带动地面尘线，炮口补转 | 坡板压到场边，入口形成清楚的纵深，玩家跑道保持畅通 |
| 双舱炮艇 | 两侧检修支臂错拍缩回，放出中间飞行线 | 左右升力舱分别反推，艇身侧移穿过已撤开的支臂之间 | 支臂回收到两侧，排焰沿管廊散开，保留两舱弱点剪影 |
| 四足潮汐巨兽 | 海锁闸板拉起，近处引流槽开始下泄，水墙退到场边 | 巨兽跨过开闸后的缺口，前足先拍水、后足承重。抬头再推出沿水面传播的第二层白沫 | 闸口维持打开，水花落回槽里，玩家看得见巨兽的脚和腹部 |
| 王冠无畏舰 | 坞环上的限位臂逐一收拢，引导灯沿舰体移动 | 舰侧从坞口转入，实际两舷喷口反推。舰身稳定后，艏部才对准玩家 | 限位臂收在航道外，照明从导航移到舰艏，战斗视线完整 |

场景机构使用与 Boss 入场同一个世界时间和状态。每段都核对提前中断、暂停恢复和换关回收。涉及可切部件时从真实占用、姿态和连通计算触发结果。首批原型优先保证交互几何和节奏，确定一条有把握的做法后，再铺开其他系列。

## 实施顺序

1. **先做一个完整样板。** 以赛博吊运场为样板，连做检修顶、实际吊运、依次释放、空载撤离、同一架直升机回归。用原速第一人称片段验证从预告到收尾。这个样板最贴近已在做的吊挂投放，能最快检验场景如何加入动作。
2. **并行补战斗的基础声画。** 先做一刀轻切、一刀重切和一次振刀的对照。先把三者区分开，再逐系列补材料变化和 Boss 终结反馈。
3. **扩到水墨、海洋、轨道。** 每系列先交一个能从跑道上完整看懂的奇观和 Boss 互动。赛博的坦克与炮艇接在同一套检修场机制之后，分别制作坡道与支臂。

每批交付包含旧新实包同机位原速片段、关键姿势或机构事件时刻和局部实际帧耗时。样板先看主轮廓、接触和空间变化，再看细部密度。

## v0.12.6 路段与机关合建

按试玩反馈重做 P1 与 P3 的连接。每处 Boss 机关挂在实际路段中心，前后路段用同材质的承台、路肩和轨道连接，玩家驶过后自然回收。开门由实际接近距离与入场时间共同编排，演员穿过同一座移动的门，再平滑接入战位。赛博四阶段依次使用前方独立的检修场地。各自可动件共享预建的静态模型。[本批明细](DESIGN.md#54-v0126-boss-场地融入道路)

## v0.12.7 Boss 场地造型重制

旧建筑方案由四套手工结构替换。建筑与各自关卡共享实际材质，色板取自峡谷、检修街区、海工平台和轨道港。后续 Boss 互动建筑沿用这个工作方式，停用此前用于建筑造型的 Skill。[本批明细](DESIGN.md#55-v0127-boss-互动建筑手工重制)
