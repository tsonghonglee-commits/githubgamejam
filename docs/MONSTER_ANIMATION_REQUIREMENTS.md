# 怪物入场动画优化需求表

依据 v0.12.3 的生产动作、第一人称距离和宗师试玩反馈制定。本轮覆盖五个系列的 35 种怪物与第一系列 Boss 的辅助运兵船，范围从入画到接回战斗。表中的评级是制作优先级，来自现有动作结构和屏幕可读性初筛。宗师另有明确试玩反馈。

**重做**指重新编排入画路线、主姿势和至少一次明确的速度转折。**大改**保留能辨认的动作主题，重编起势、受力和结束姿势。共同验收看玩家机位下的剪影、节奏与真实部件接触。每种怪物保留入场时长、终点战位、可斩部件和战斗接续。运输船吊点与阵型约束随实际几何检查。

体素特效先应用在三个关键镜头。宗师墨浪在接地时扩散，剑痕沿存活刃尖延伸。潮汐巨兽在前足扑落之后，用第二层贴地白沫衔接抬头。无畏舰由两舷实际推进口分别喷流，先看到反推，再看到整舰定姿。

| 系列 | 怪物 | 处理 | v0.12.3 的主要问题 | 新入场验收重点 |
| --- | --- | --- | --- | --- |
| 工业 | 刀兵 `normal` | 大改 | 滑跪主题可辨，远处身段和刀的动势弱 | 斜身拖刃切入，压低滑跪，刀从低位大幅挑起再起身 |
| 工业 | 肉盾 `tank` | 大改 | 跃落撑锤可辨，悬空到承重的反差小 | 抬锤起跳，砸地压肩，借锤柄撑起重心 |
| 工业 | 射手 `ranged` | 重做 | 滑步与托枪主要在同一轮廓内发生 | 侧身撤步，枪横扫到胸前，双手托枪定向 |
| 工业 | 无人机 `drone` | 重做 | 五机共用相同掠过和转身 | 贴地切过近侧，快速抬头翻正，小幅回弹后定点 |
| 工业 | 导弹机 `missile_drone` | 重做 | 飞行路线与轻机接近，弹舱缺少受力动作 | 高位斜降，拉起制动，弹舱错拍打开 |
| 工业 | 盾机 `shield_drone` | 重做 | 横移与轻机相似，正面盾的轮廓出现过晚 | 斜侧机身进场，横滚亮盾，立盾刹停 |
| 工业 | 截击机 `interceptor` | 重做 | 速度与转向节拍接近其他飞行怪 | 最快一拍掠过，宽弧急转，翼面回正前停一拍 |
| 工业 | 布雷机 `mine_layer` | 重做 | 进场弧线和小机相似，重量感不足 | 宽弧缓压，先下沉再上浮定姿，挂舱逐段伸出 |
| 工业 | 双堆 Boss `boss` | 大改 | 吊装辨识度高，松钳后压身和展开挤在一起 | 松钳坠落、接地压身、双侧分拍张开，提前断吊点仍可投放 |
| 工业 | 辅助运兵船 `boss_carrier` | 大改 | 吊架关系可读，卸载后的离场节奏平 | 保留真吊点对齐，释放后先卸重抬艏，再带空架撤离 |
| 水墨 | 墨刃客 `ink_swordsman` | 重做 | 直线接近加一次通用刹停 | 低身拖刃，侧穿后压脚刹停，反挑出警戒轮廓 |
| 水墨 | 折锋长枪 `ink_spear` | 重做 | 枪长和身体支点在入场中利用不足 | 横枪卷身切入，扎枪下压承重，拔枪回身 |
| 水墨 | 朱符使 `ink_talisman` | 重做 | 向前滑行时两手小幅先后摆动 | 半转身掠入，定步合印，再大幅展开双手 |
| 水墨 | 纸鹤机关 `ink_crane` | 大改 | 扇翅有物种特征，滑行线平缓 | 展翼滑翔，折翼掠低，拍翼抬升再停住 |
| 水墨 | 朱印宗师 `ink_master` | 重做 | 原跃落路线与上一版接近，近景动作区别小 | 横穿车道、近景停空、急坠立刃、双剑分拍、撤步接战 |
| 赛博 | 破门突击手 `cyber_breacher` | 重做 | 沿普通人形同一曲线逼近 | 肩部领跑、压低冲入、侧踏刹停、扳枪到位 |
| 赛博 | 折盾镇暴兵 `cyber_riot` | 重做 | 落地前后盾面方向变化不明显 | 侧身进场，重踩扭身，盾面翻转封线 |
| 赛博 | 棱镜狙击手 `cyber_sniper` | 重做 | 直线滑行与突击兵接近 | 侧移后蹲低，枪先扫高再落到稳定瞄线 |
| 赛博 | 蛛翼侦察机 `cyber_drone` | 大改 | 减速主要靠小幅俯仰 | 侧翼不对称切入，横摆调头，左右推进舱反向制动 |
| 赛博 | 中继队长 `cyber_captain` | 大改 | 最后到场可读，指令姿势与三名队员剪影相近 | 最后解锁离开直升机，落脚扫视，整臂高举发令后收枪 |
| 赛博 | 侧击双刃 `cyber_flanker` | 重做 | 与队长共用降落和起身模板 | 第一个脱钩，贴路侧滑，低跨步急停，双刃错向张开 |
| 赛博 | 重火压制手 `cyber_suppressor` | 重做 | 仅下落高度和双臂角度与队友不同 | 重装直落，深蹲分脚吸震，抬重炮二次下沉 |
| 赛博 | 观测标定手 `cyber_spotter` | 重做 | 共用降落模板，缺少观察节拍 | 脱钩后高位带侧身落地，低位扫描后立起标定装置 |
| 赛博 | 断尾直升机 `cyber_helicopter` | 大改 | 侧旋可辨，但与前一阶段缺少演出衔接 | 先吊挂投放小队并撤离，下一阶段返回时偏航侧滑、机鼻反向制动、回摆后转稳 |
| 赛博 | 裂履主战坦克 `cyber_tank` | 大改 | 履带压身短，转舷和车体重量弱 | 斜车身进场，先车身急停再压悬挂，炮口补转 |
| 赛博 | 双舱炮艇 `cyber_gunship` | 大改 | 双舱可辨，船体惯性与矢量节奏小 | 异侧侧倾切入，双舱分别反推，艇身迟一拍回正 |
| 海洋 | 掠浪鳍刃 `sea_skimmer` | 重做 | 短小单次抛物线，掠浪特征弱 | 先贴水压低，出水腾跃，斜身回落后收鳍 |
| 海洋 | 礁壳重蟹 `sea_crab` | 重做 | 多足摆动缺少先落脚再承重 | 横向进场，依次落两排脚，壳体下沉后双钳分拍展开 |
| 海洋 | 电棘海鳗 `sea_eel` | 大改 | 正弦摆尾可辨，头和尾基本同拍 | 从低处折上，头先改向，尾部滞后甩过再定向 |
| 海洋 | 翼潮鳐机 `sea_ray` | 大改 | 双翼拍动和机体移动的节拍均匀 | 先收翼下掠，靠一次强拍拉升，左右翼分开找平 |
| 海洋 | 四足潮汐巨兽 `sea_leviathan` | 大改 | 高扑能辨认，四肢和浪花挤在同一时刻 | 收腿高扑，前足先撞地，后足接重，抬头再扩浪 |
| 轨道 | 轨道重步机 `empire_walker` | 重做 | 四足主要做同步下落姿势 | 悬降后按前后脚对着地，舱体重压，再架炮 |
| 轨道 | 星矛突骑 `empire_lancer` | 重做 | 与其他人形同一逼近曲线，星矛缺乏贯穿动作 | 抱矛加速，斜身急刹，拉开后脚再递出矛尖 |
| 轨道 | 棱盾哨卫 `empire_sentinel` | 重做 | 盾、臂和脚缺少明确的部署次序 | 正面停步，半跪展开盾，另一侧武器再转出 |
| 轨道 | 折翼战机 `empire_fighter` | 大改 | 滚转主题明确，速度转折和翼尖行程小 | 斜俯冲接大幅滚转，折翼过渡后急拉平 |
| 轨道 | 王冠无畏舰 `empire_dreadnought` | 大改 | 转舷可辨，船体与推进器同拍缓停 | 大角度露舰侧，近处横移制动，两舷推进器错拍收束 |
