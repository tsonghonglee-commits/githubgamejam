## 独立场景概念

用户另行强调场景也必须走同样流程。角色板的背景不代替场景概念。以下四张场景板同样由内置图像生成工具制作，仍是制作目标而非引擎画面。

| 场景板 | 空间与构造要求 |
| --- | --- |
| [墨武山门](environment-02-ink-v1.png) | 严格黑白灰与朱红，去蓝绿雾和绿色竹子；干燥石板、飞檐山门、错落亭台、灰阶竹影与层叠远山。 |
| [特勤追杀](environment-03-pursuit-v1.png) | 黑色城市体量、少量功能灯，路外斜撑/侧台/检查口/检修楼梯、远景高架和立体建筑深度，上空留断口。 |
| [巨浪前线](environment-04-tidal-v1.png) | 低栏桥面、可见连续海平面、错位卷浪和泡沫、支撑与服务平台的真实海上尺度，避免屋顶式尖墙浪。 |
| [轨道船坞](environment-05-orbital-v1.png) | 黑骨瓷紫金的舰坞构造、交叉支撑和控制塔、巨型泊舰与不封顶坞环、分层航道和深星空。 |

场景提示词共同合同：first-person eye height 1.75m, straight flat continuous four-lane combat road, clear central sightline and upper aerial space, fine stepped voxel modular geometry, physical load-bearing architecture, foreground/midground/horizon scale, restrained material detail, original designs. No character/weapon/HUD/arrows, sharp turns or obstacles in lane interiors, infinite identical boxes, rainbows, photorealistic CGI or copied logos. 生成图上的尺度字样、远处飞船与小字只作设计参考；生产以本项目跑道宽度、可切Boss尺寸、既有相机和性能预算为准。

生成稿中的微小螺丝、字样、光照与环境湿润效果不是自动落地承诺。模型对照优先完成可读的比例、剪影、层甲、武器、连接和动作；所有新增身体细节继续是实际占用体素。不同大小单位采用适合其物理体积的网格，真实材料、部件连通、可再切残骸与有限特效池优先。实际模型图与检查结果另存发行复核目录，不混同这四张概念板。
